# Capability Matrix Template

Use one row per enterprise activity.

| Field | Question |
|---|---|
| Activity | What exact work is being performed? |
| Domain | Banking, DWH, trading, etc. |
| System of record | Where does authoritative truth live? |
| Determinism required | Must identical inputs yield identical outputs? |
| Error tolerance | What happens if the system is wrong? |
| Structured input | How much input is already structured? |
| Unstructured input | Is language/document interpretation material? |
| Human cognitive work | What does a person currently reason about? |
| Workflow variability | Fixed, bounded-variable, or open-ended? |
| Cross-system burden | How many systems/tools are coordinated? |
| Ordinary automation | What SQL/API/rule/workflow/script solution already exists? |
| WHY NOT ORDINARY SOFTWARE? | Why is conventional software insufficient? |
| ML fit | None / weak / medium / strong |
| LLM fit | None / weak / medium / strong |
| Agent fit | None / weak / medium / strong |
| Human role impact | Assist / reduce / replace / create new capability / none |
| Software-layer impact | Improve / augment / collapse / no change |
| Economics | Labour, time, infra, support and control costs |
| New risks | Hallucination, nondeterminism, privacy, compliance, control, latency |
| Evidence | Sources and measurements |
| Evidence level | E0–E4 |
| Confidence | 0–100% |
| Decision | Deterministic / ML / LLM / agent / hybrid / unresolved |
