# Research Questions

## Primary question

For every major activity inside a modern enterprise, which work should remain deterministic, which benefits from analytical ML, which benefits from LLMs, and which genuinely benefits from autonomous or semi-autonomous agents?

## Secondary question

For each AI-supported activity, does AI:

1. improve an existing activity,
2. remove or reduce human labour,
3. collapse an existing software layer,
4. create a new capability,
5. or merely add complexity with little net value?

## Mandatory test

Every proposed agent or LLM use case must answer:

> WHY NOT ORDINARY SOFTWARE?

The burden of proof is on the AI proposal, not on the deterministic alternative.

## Research dimensions

- Where does authoritative truth live?
- Must identical inputs always produce identical outputs?
- How much error is tolerable?
- Is the hard part retrieval, reasoning, interpretation, diagnosis, or action selection?
- Is the workflow fixed or variable?
- Are inputs structured or unstructured?
- How many systems must be coordinated?
- What conventional automation already exists?
- What human role currently performs the cognitive work?
- What measurable economic value is created?
- What new failure modes, compliance risks or control problems appear?

## Domain scope

Retail banking, investment banking, trading, insurance, betting, e-commerce, telecom, healthcare, government, ERP/finance, CRM/sales, customer service, software engineering, cyber/security, data engineering, DWH/BI/reporting, compliance, operations, HR, legal and procurement.
