# Problem Statement

## Primary problem

Determine where LLMs and agentic systems create genuine economic or operational value within existing enterprise technology estates, and where deterministic software, databases, rules engines, ETL/DWH platforms and conventional automation remain superior.

## Anti-hype constraint

Do not assume that agents replace enterprise software. Test the boundary.

A proposed AI layer must justify why it is better than ordinary software for the specific activity. Static retrieval, authoritative record access, repeatable calculations, fixed workflows, scheduled reporting and stable ETL paths should default to deterministic implementation unless evidence demonstrates otherwise.

## Research focus

For each activity, identify:

- system of record
- determinism requirement
- error tolerance
- human cognitive work
- unstructured-input burden
- decision variability
- workflow variability
- cross-system coordination burden
- existing automation
- LLM fit
- agent fit
- economics
- operational risk
- evidence quality

## Core distinction

AI may be highly valuable around interpretation, diagnosis, exception handling, research, orchestration and human cognitive work without replacing the deterministic systems that hold truth, execute regulated calculations or perform authoritative transactions.
